# 🚀 TransitMind AI

### *AI-Powered Intelligent Urban Transport Optimization Platform*

## 📌 Overview

TransitMind AI is a smart public transport optimization platform designed for urban mobility systems like Bengaluru.

The platform combines:

LSTM-based passenger demand forecasting
YOLO crowd detection
GTFS route intelligence
Traffic-aware scheduling
Dynamic bus allocation
Professional admin dashboard

to create an intelligent transport management system capable of optimizing bus operations in real time.

---

# ✨ Features

* AI-based passenger demand forecasting
* Real-time crowd detection using YOLOv8
* GTFS-based route and stop intelligence
* Dynamic bus allocation & scheduling
* Traffic congestion analysis using Google Maps APIs
* Interactive live dashboard
* Admin login & manual bus allocation
* Alerts for overcrowding and congestion
